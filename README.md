# .github

Org-weite Vorgaben für alle Repos im Personal Hub:

- `ISSUE_TEMPLATE/`: Vorlagen für Auftrag, Fehler und Idee (gelten für jedes Repo ohne eigene Vorlagen)
- `pull_request_template.md`: Standard-PR-Beschreibung
- `labels.json` + `scripts/sync-labels.sh`: das Label-Protokoll, synchronisiert in alle Repos
- `profile/README.md`: Profilseite der Organisation

Dieses Repo muss **öffentlich** sein, damit GitHub die Vorlagen org-weit verwendet. Es enthält keine Geheimnisse.
